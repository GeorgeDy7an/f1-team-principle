# 开发历程与验证记录

## 从设计到可玩原型

1. **确定核心体验**：围绕车队经营、快速赛季和少量关键决策定义范围，舍弃逐圈模拟与玩家实时操控。
2. **建立比赛原型**：用车手与赛车能力、随机波动、退赛和少量冷门生成最终名次。早期版本通过批量赛季模拟检查成绩分布与异常事件频率。
3. **引入持续经营**：逐步加入车队研发、车手成长、合同与新人市场，使赛季之间形成因果联系。
4. **形成生涯叙事**：加入人格反馈、赛季报告与十年结算，尝试让冠军、弱队重建和车手培养都有可见成果。
5. **根据反馈改版**：针对手机端内容过长、按钮被遮挡、合同与新人选择不够直观的问题，反复调整分页、布局和操作步骤。
6. **制作离线双语版**：从较完整版本移除平台依赖，加入首页中英文切换，并对离线玩法、存档与多种手机视口进行检查。

## 已使用的验证方式

- 使用固定随机种子进行批量模拟，观察积分、胜率、退赛和冷门分布。历史报告对应当时的版本和参数，不直接代表后续版本的平衡结果。
- 在桌面浏览器以手机视口测试主要页面、选择和按钮可访问性；对离线版本以阻断网络的方式检查资源与操作。
- 通过脚本检查赛季推进、十年生涯边界、阵容约束以及存档恢复。自动化测试与真实玩家体验各有范围，测试通过不等于所有设备和随机分支都已经覆盖。

## 分工与方法

项目由 GEORGE 主导玩法方向、用户体验要求和迭代决策。开发过程中结合 AI 辅助编写、调试和测试代码，并根据实际界面反馈持续调整。这个作品集着重展示设计取舍、问题定位与迭代方法；为保护完整作品，公开演示和示例不包含完整游戏代码。
